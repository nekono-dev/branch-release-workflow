# プロダクト概要

branch-release-workflow は、Claude Code と Codex で作業する開発者が、リポジトリのブランチ運用とプレビュー・リリース手順を共有するためのスキルと CLI。保護ブランチへの直接の commit・push を防ぎ、作業ブランチでの変更からレビュー、配備、作業の再開と片付けまでを支援する。

## 主な機能

- 作業ブランチの命名規則と分岐元に従ってブランチと worktree を作成する。途中の作業はローカルまたはリモートのブランチから再開できる。
- 保護ブランチと宣言外のブランチへの commit・push を判定する。Claude Code ではフックで拒否し、Codex ではエージェントが実行前に `guard` の結果を確認する。保護規則は作業ブランチの許可より優先し、push は実際の送り先で判定する。
- 作業ブランチのプレビュー URL を宣言から算出し、CI と配備設定の整合性を検査する。Cloudflare Workers ではプレビューと配備の workflow 雛形を生成できる。
- 分岐元への取り込み、または保護ブランチへの PR を確認してから、ローカルの worktree と作業ブランチを片付ける。未コミットの変更がある worktree は残す。

## 利用場面

チーム開発や CI・クラウドセッションで、複数の開発者やエージェントが共通のブランチ規則で作業する。プレビューの配信方法はリポジトリごとに選べる。Cloudflare Workers では、既存の Worker を使う構成と、本番用と開発用で Worker を分ける構成に対応する。

## 提供価値

リポジトリに登録した `.branch-release-workflow.json` を運用の正本とし、開発環境と CI が同じ規則を参照する。ブランチ名、公開先、配備先などのアプリケーション固有の値は、導入先の宣言に置く。保護ブランチの指定は直接作業の可否を決め、配備先の指定は CI がどこへ配備するかを決める。
