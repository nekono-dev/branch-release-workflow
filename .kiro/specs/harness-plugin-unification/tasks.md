- [ ] 2.3 BRW のフックの信頼を登録できるようにする

- [ ] 3.2 `brw setup` が対象のハーネスを決めてフックを導入・信頼登録するようにする

  - Codex が対象のとき、検査 → 信頼の登録 → 結果の表示を行い、未導入・無効のときは導入に必要な 2 つのコマンドと導入先の宣言の記入先を表示する。登録できない理由と、手動で信頼する手順を区別して案内する。終了コードは、完了を 0、直す必要があるものを 1、確認不能を 3 とし、非対話でも失敗を非 0 で示す。信頼の確認を飛ばすオプションは使わない。
  - 宣言が Claude だけのリポジトリで `codex` が無くても完了し、Codex が対象で `codex` が無いと失敗する。各分岐の表示と終了コードを、偽の Codex を使う契約テストで確認できる。
  - _Boundary: setup-cli_
  - _Depends: 2.3, 3.1_
  - _Requirements: 4.1, 4.2, 4.4, 4.6, 4.7, 6.3, 7.3_
